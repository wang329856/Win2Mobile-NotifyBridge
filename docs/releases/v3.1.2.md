# Win2Mobile 3.1.2 隐私修复版

2026-10-02 发布。Windows 文件／MSIX 版本 3.1.2.0，Android versionName 3.1.2、versionCode 30102。

- Windows 清理过期及超量通知时，清除当前 SQLite/WAL 的正文残留；首次启动整理旧数据库，保留有效消息、电脑身份、授权及进度。
- Android 删除、清空、开始新一轮、移除电脑及重新配对时撤回对应系统消息通知；接收与删除串行处理，防止晚到显示。后台状态通知保留；启动清理旧版本遗留的无记录通知。
- Windows 队列项失效后清空详情及文本撤销记录，禁用复制入口。

下载：[GitHub v3.1.2](https://github.com/wang329856/Win2Mobile-NotifyBridge/releases/tag/v3.1.2)。Windows 安装套件为 `Win2Mobile-Setup-x64.zip`，Android 为 `Win2Mobile-3.1.2-release.apk`，同目录提供 `SHA256SUMS.txt`。

签名、Publisher、应用包身份不变，可覆盖相同正式签名的旧版并保留数据。Windows 自签名证书指纹 `81D47A2CADFAEEA35CFB47F1D18C2DA9F1193C19`，有效期至 2026-12-31，包带 DigiCert RFC 3161 可信时间戳。新电脑仍需核验并信任证书。Android 发布签名 SHA-256 为 `24688133b730879b78ddf8413a68d2bd1f8b1637acc3ebab823cb6f3decec2cd`；不能覆盖调试签名版本。

验证细节与适用边界见 [隐私修复记录](../security-fixes-2026-10-02.md)。修复不会追回旧备份、系统快照或其他应用保存的副本。真实手机通知栏和锁屏行为仍需实机复核。
