# Win2Mobile 3.1.1 正式构建记录

打包日期：2026-10-02。GitHub 正式版：[v3.1.1](https://github.com/wang329856/Win2Mobile-NotifyBridge/releases/tag/v3.1.1)。安装包使用独立 Android 发布签名和现有 Windows 自签名证书，未上架应用商店。

## 更新

- 手机启动图标与 Windows 的电脑／手机／通知图标统一，支持圆形、自适应形状及 Android 13 单色主题图标。状态栏使用符合 Android 规范的白色透明图标。
- 手机转发通知标题显示「来源应用 · 原标题」，例如「微信 · 张三」，不依赖部分系统会隐藏的副标题。空应用名称使用应用标识，空标题使用「新通知」。正文与点击定位原消息保持不变。
- 新扫码页使用 Compose 竖屏布局，圆角取景框、青绿扫描线、手电筒、返回与相机重试入口。连接电脑和更新地址分别显示提示；更新地址仍校验原电脑身份和证书。相机随页面前后台停止／恢复，只解码二维码。
- 两端保留 3.1 的暂停／继续、自动通道选择、Room v4 迁移和通知去重等行为。Windows 简化名称后的文件版本为 3.1.1.1；Android versionName 为 3.1.1，versionCode 为 30101。

## 安装包

- Windows 安装版：`dist/releases/v3.1.1/Win2Mobile-Setup-x64.zip`。包含自包含 x64 MSIX、现有公钥证书、安装脚本和说明。在 Windows 10 2004 及以上运行。窗口、开始菜单和托盘显示名称统一为 `Win2Mobile`，包身份不变。
- 仅发布 Windows 安装版，不提供无法采集系统通知的受限便携版。
- Android：`dist/releases/v3.1.1/Win2Mobile-3.1.1-release.apk`。Release 构建、非 debuggable；不包含调试预览和迁移验证 Activity。最低 Android 8.0。
- 同目录包含 SHA-256 清单与本记录。不要分发任何私钥、PFX、PKCS12 或签名密码配置。

## 签名与升级

Android 使用独立 RSA 3072 位发布密钥，证书 SHA-256：

`24688133b730879b78ddf8413a68d2bd1f8b1637acc3ebab823cb6f3decec2cd`

密钥保存在本机 `%LOCALAPPDATA%/Win2Mobile/Signing/win2mobile-release.p12`，密码配置受当前 Windows 用户 DPAPI 保护。私钥不在仓库和交付包中。后续版本必须复用此密钥；应通过安全方式备份私钥与解密后的密码以支持换机恢复，单独复制 DPAPI 配置到其他 Windows 用户无法解密。

**现有 debug APK 无法被正式签名 APK 覆盖。** 安装正式包前应先保留所需数据，再卸载调试版；新安装后需重新授权和配对。相同正式签名的后续版本可正常覆盖升级。本机实机安装已在用户明确允许后完成旧版数据备份、卸载调试版和正式版安装。

Windows 沿用现有自签名证书 `CN=Win2Mobile`，指纹 `81D47A2CADFAEEA35CFB47F1D18C2DA9F1193C19`，当前有效期至 2026-12-31。签名在本机验证为 Valid，现有安装可覆盖升级并保留数据；其他电脑首次安装需自行核验并信任该证书。它不是公共 CA 签名，也不代表 Microsoft Store 审核通过。本次不导入证书或修改系统信任。
