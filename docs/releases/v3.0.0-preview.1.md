## 主要变化

- 扫码连接电脑，在桌面核对并批准配对请求；二维码 120 秒有效。
- HTTPS / WSS 加密传输，手机绑定电脑证书指纹；可撤销已配对设备。
- 两端持久化通知历史，支持断线补发、事件去重和送达确认；历史重放不成批响铃。
- 桌面提供通知访问状态、来源过滤、暂停、近期通知、系统托盘和可选登录启动。
- 手机提供通知历史、电脑管理、搜索筛选和后台接收诊断。
- 使用 Windows 官方通知监听接口及 Android 原生前台接收服务。
- 清理旧 Flutter、旧 ntfy 轮询实现和过时构建入口；完整源码与构建脚本保留在仓库。

## 安装桌面端

要求 Windows x64，Windows 10 build 19041 或更新版本。应用自包含，不需要额外安装 .NET Runtime。

1. 下载 Windows ZIP，解压到普通目录。更新前请从托盘退出正在运行的 Win2Mobile。
2. 首次安装需信任本次发布的开发证书。双击 `Win2Mobile-Development.cer`，核对 Subject 为 `CN=Win2Mobile`，指纹为 `81D47A2CADFAEEA35CFB47F1D18C2DA9F1193C19`。点击「安装证书」，选择「本地计算机」，按提示授予管理员权限，手动选择「受信任人 / Trusted People」证书存储。不要选择「受信任的根证书颁发机构」。这会允许本机信任使用该证书签名的应用。[微软安装信任说明](https://learn.microsoft.com/en-us/windows/msix/package/create-certificate-package-signing)
3. 在解压目录打开**当前用户的普通 PowerShell**，执行以下内置命令安装到系统应用卷（通常为 C 盘）。此方式无需修改脚本执行策略或机器默认应用存储位置：

   ```powershell
   $systemVolume = Get-AppxVolume | Where-Object IsSystemVolume
   Add-AppxPackage -Path .\Win2Mobile-3.0.0.0-x64.msix -Volume $systemVolume
   ```

4. 从开始菜单打开「Win2Mobile 局域网通知桥」，点击「授权通知访问」，允许系统提示。

ZIP 中另附 `Install-Win2Mobile.ps1`，用于允许本地脚本执行的环境：`./Install-Win2Mobile.ps1 -PackagePath './Win2Mobile-3.0.0.0-x64.msix'`。脚本检查签名并选择系统卷，不导入证书。

证书有效期截至 **2026-12-31 00:24:38（北京时间）**，此 MSIX 未加时间戳；证书到期后，新安装或签名校验可能失败，需要后续重新签名的版本。该证书公钥文件的 SHA256 为 `BD5EC3A6846D2AD44301A4A2DEB312F04FB862BB103A91155A7E89BAFF99941F`。发布附件不包含私钥或密码。

## 安装手机端与配对

1. 下载 APK 到 Android 手机，打开安装，按系统提示允许当前浏览器或文件管理器安装此应用。
2. 打开 Win2Mobile，允许通知；使用扫码功能时授予相机权限。
3. 手机与电脑连接到可互通的同一局域网。在手机「电脑」页选择「扫码连接电脑」，扫描桌面「配对手机」中的二维码。多网卡电脑请先选择手机能够访问的 IPv4 地址。
4. 在电脑核对设备名称并批准配对，然后点击「发送测试通知」，确认手机收到。
5. 如连接被拦截，检查 Windows 私人网络的 TCP 47721 入站权限，以及 Wi-Fi 是否启用了访客隔离。程序不会自动修改防火墙。

也可用 ADB 安装：

```powershell
adb install -r .\Win2Mobile-3.0.0-debug.apk
```

## 从旧版升级

- v3 使用新的配对协议，旧 IP / topic 配置不会迁移；两端更新后需重新扫码。
- Android 保留 `com.notifforward.app` 应用 ID。覆盖安装必须使用同一签名；如旧 APK 签名不同，先备份所需旧数据，再卸载旧 App 安装本版。卸载会删除旧 App 的本地数据，新版不会导入 Flutter 历史。
- 已通过本次本机测试安装同一 APK 的设备使用相同签名，不需要为了下载此 Release 再次卸载。
- Windows 使用独立 MSIX 包身份，请退出旧代理，避免同时采集。

## 验证与当前限制

本地后端集成测试、桌面采集状态测试和 Windows Release 构建通过；Android 26 项 JVM 测试通过，lint 无错误，APK 签名验证通过。Windows 和 Android 两项 [GitHub Actions](https://github.com/wang329856/Win2Mobile-NotifyBridge/actions/runs/36849260097) 均通过。本机已安装并启动两端，Android 实测设备为 V2352A / Android 16；用户反馈手动测试通过。

- 当前仅支持可互通的局域网，不提供公网中继或云推送。
- 采集范围为 Windows 系统 Toast；应用自绘弹窗、聊天历史不在采集范围。启动前已有的通知只作为基线，暂停期间的内容不会补发。
- Android Doze 与厂商后台限制仍可能影响接收；前台服务不保证整晚持续联网。不同手机的息屏表现仍需验证。
- Windows 非系统应用卷的目录联接曾触发 `0x800701C0` 启动失败；本版推荐使用系统卷安装。上述安装命令不会迁移已安装到其他卷的同版本应用。
- 当前提供 Windows x64 与 Android 开发签名安装包，尚未配置正式发布签名；不提供 iOS 或 Windows ARM64 原生包。

本次下载的两端安装包与已完成本机安装测试的文件一致；源码、CI 和本机验收记录可在仓库查看。
